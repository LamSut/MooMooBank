# MooMooBank

MooMooBank is a Java-based desktop banking system built with Java Swing for the user interface and MySQL for data storage. This system simulates common banking functionalities in a secure and user-friendly way. 
Refer to this document for additional details: [MooMooBank](https://github.com/LamSut/MooMooBank/blob/master/LamB2111933_ThanhB2111952.pptx)


## Features

-  **Sign Up** – Create a new account with secure credentials and user info  
-  **Login** – Authenticate existing users with a username and password  
-  **Show/Hide Balance** – Toggle visibility of your account balance  
-  **Show Information** – View your personal and account details  
-  **Show History Balance Changes** – Track and display your transaction history  
-  **Internal Transfer** – Send money to another user within the same bank  
-  **External Transfer** – Transfer funds to accounts outside the bank  
-  **Phone Recharge** – Top up a mobile phone using your account balance  
-  **Enter PIN** – Verify sensitive actions with a personal identification number  
-  **Change Password** – Update your account password securely



## Technologies

- **Java (Java Swing)** – For developing the desktop GUI  
- **MySQL** – For backend data storage and retrieval  
- **JDBC** – To connect Java application with the MySQL database
